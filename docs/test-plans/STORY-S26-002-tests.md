### TC2: config.yml is valid YAML (PyYAML or yq parse)

## Adversarial Probes (per tester doctrine §Adversarial Probes)

### Configuration space

- **Empty config.yml** — `blank_issues_enabled: true` only — should still parse (TC2 GREEN)
- **Invalid YAML** (mismatched quotes, tabs vs spaces) — TC2 should FAIL (negative case)
- **Missing file** — TC1 should FAIL
- **YAML with embedded comments** — TC2 should PASS (PyYAML handles `#` comments natively)

### Git tracking space

- **config.yml in `.gitignore` line 81** (current RED state) — TC3 FAIL (correctly detects bug)
- **config.yml removed from `.gitignore` but still untracked** — TC3a FAIL + TC3b FAIL (regression on impl)
- **config.yml tracked AND removed from `.gitignore`** — TC3a PASS + TC3b FAIL exit 1 (correct GREEN)

### Idempotency / regression

- **d-test run twice** — exit code 0 both times (no side effects)
- **d-test run with `set -eo pipefail`** vs without — same exit code discipline
- **d-test concurrent run** — should not race (file-level checks, no DB)
